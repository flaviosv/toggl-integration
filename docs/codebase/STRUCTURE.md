## Module Organization

### `internal/webhook`

- **Purpose:** HTTP entrypoint for `POST /webhooks/toggl` — verifies the HMAC signature against the raw body, parses the event envelope, dispatches to `sync`.
- **Location:** `to-jira/internal/webhook/`
- **Key files:** `handler.go` (`Handler.Receive`, `verifySignature`)

### `internal/toggl`

- **Purpose:** Toggl webhook envelope/event types, description parsing (`[SLUG-NUMBER] text`), and running-entry normalization. No JIRA or HTTP knowledge.
- **Location:** `to-jira/internal/toggl/`
- **Key files:** `envelope.go` (wire types + `ParseEnvelope`), `parse.go` (`ParseDescription`), `normalize.go` (`NormalizeEntry`)

### `internal/jira`

- **Purpose:** JIRA Cloud REST API v3 client — worklog CRUD, Atlassian Document Format (ADF) comment build/extract, token-expiry warning.
- **Location:** `to-jira/internal/jira/`
- **Key files:** `client.go` (`Client`, `do`), `worklog.go` (CRUD + error classification), `adf.go` (`BuildComment`/`ExtractTogglID`), `tokenexpiry.go`

### `internal/sync`

- **Purpose:** Orchestration layer — maps Toggl events to JIRA calls, owns dry-run branching and OTel span/metric emission.
- **Location:** `to-jira/internal/sync/`
- **Key files:** `process.go` (`Processor.Process`, create/update path), `process_delete.go` (`Processor.ProcessDelete`)

### `internal/shared`

- **Purpose:** Cross-cutting infrastructure plumbing, deliberately generic and reused across any future service in this monorepo.
- **Location:** `to-jira/internal/shared/{config,di,logger,server,telemetry}/`
- **Key files:** `config/config.go` (env loading + `validator/v10`), `di/dependency.go` (staged `BuildDependencies`), `logger/logger.go` (slog + context carrier), `server/server.go` (`Run` with graceful shutdown), `telemetry/telemetry.go` (OTel bootstrap + `Metrics`)

### `internal/routes`

- **Purpose:** Registers HTTP routes on the gin route group carrying the middleware chain (never directly on the engine, to avoid bypassing middleware).
- **Location:** `to-jira/internal/routes/routes.go`

### `mcp/src`

- **Purpose:** The entire `toggl-mcp` TypeScript package — one MCP tool (`list_time_entries`) reading Toggl Track's REST API. See `mcp/CLAUDE.md` for full package-level architecture, public API, and testing detail.
- **Location:** `mcp/src/`
- **Key files:** `index.ts` (entrypoint), `config.ts` (`loadConfig`), `toggl/client.ts` (`TogglClient`), `cache/project-cache.ts` (`getProjects`), `time-entries/curate.ts` (`toCuratedEntry`), `tools/list-time-entries.ts` (`registerListTimeEntries`)

## Where Things Live

**Webhook sync (create/update/delete a JIRA worklog from a Toggl event):**

- HTTP entrypoint / signature verification: `to-jira/internal/webhook/handler.go`
- Payload parsing / normalization: `to-jira/internal/toggl/`
- Orchestration / business rules: `to-jira/internal/sync/`
- JIRA API calls: `to-jira/internal/jira/`
- Configuration: `to-jira/internal/shared/config/config.go`, `to-jira/.env.sample`

**Time-entry listing (`list_time_entries` MCP tool):**

- MCP entrypoint / tool registration: `mcp/src/index.ts`, `mcp/src/tools/list-time-entries.ts`
- Input validation: `mcp/src/tools/schemas.ts`
- Toggl API calls: `mcp/src/toggl/client.ts`
- Project-name caching: `mcp/src/cache/project-cache.ts`
- Configuration: `mcp/src/config.ts`, `mcp/.env.sample`

## Special Directories

**`to-jira/docs/`:** Known-limitations documentation (`NOT_IMPLEMENT.md`) — edge cases deliberately deferred from v1, not solved, kept here so they aren't silently rediscovered.

**`mcp/openapi/`:** Committed Toggl OpenAPI spec (Swagger 2 + generated OpenAPI 3), the source for `mcp/src/toggl/generated.ts` via `npm run generate:openapi`. Not hand-edited.

**`.specs/`:** Owned by the `tlc-spec-driven` skill — feature specs, design docs, task breakdowns, and the decision log (`STATE.md`). Out of scope for `architecture-evaluate` to modify; read-only source material for this doc set.
